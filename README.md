# txfetch-c
This is a rewrite of txfetch which i wrote in Shell Script.

## Why?
- To apply what i learn
- Speed maybe...

## Setup

- **Clone the repository**
```
git clone https://github.com/RishOnBash/txfetch-c.git
cd txfetch-c
```

- **Install**
```
make install
```

- **Run**
```
~ $ txfetch
```

## Uninstallation
```
make uninstall
```
